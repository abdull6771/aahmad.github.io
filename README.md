# Abdullahi Ahmad - Portfolio

A modern React-based portfolio website for Abdullahi Ahmad, an AI Research Engineer and Machine Learning Specialist.

## Features

- 🎨 Modern, responsive design with dark mode support
- ⚡ Built with React 18 and Vite for fast development
- 🧭 Client-side routing with React Router
- 📱 Mobile-friendly layout
- 💬 Interactive chat widget
- 🎯 Multiple sections: About, Skills, Experience, Projects, Notes, Education, Awards, Publications, Contact

## Tech Stack

- **Frontend**: React 18, React Router DOM
- **Build Tool**: Vite
- **Styling**: CSS with CSS Variables
- **Icons**: Font Awesome 6.4

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The app will open at `http://localhost:3000`

## Build

```bash
npm run build
```

This creates a production build in the `dist/` directory.
